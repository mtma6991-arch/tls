# ارائه‌دهندگان DNS پشتیبانی‌شده

این ابزار از پلاگین‌های DNS خودِ `acme.sh` استفاده می‌کند که بیش از ۱۴۰ ارائه‌دهنده
را پوشش می‌دهد. مقدار `DNS_PROVIDER` در فایل env باید نام یکی از این پلاگین‌ها باشد.

## رایج‌ترین گزینه‌ها

| ارائه‌دهنده          | مقدار `DNS_PROVIDER` | متغیرهای لازم در env                                  |
|----------------------|-----------------------|--------------------------------------------------------|
| Cloudflare            | `dns_cf`              | `CF_Token`, `CF_Account_ID`                             |
| AWS Route53           | `dns_aws`              | `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`           |
| Google Cloud DNS       | `dns_gcloud`           | نیاز به `gcloud auth login` از قبل                      |
| DigitalOcean           | `dns_dgon`             | `DO_API_KEY`                                            |
| Namecheap               | `dns_namecheap`        | `NAMECHEAP_USERNAME`, `NAMECHEAP_API_KEY`, `NAMECHEAP_SOURCEIP` |

فهرست کامل پلاگین‌ها در مخزن رسمی acme.sh موجود است (پوشهٔ `dnsapi`)؛ نام فایل بدون
پسوند `.sh` همان مقدار `DNS_PROVIDER` است.

## چرا ارائه‌دهندهٔ DNS من در لیست رسمی نیست؟

اگر DNS دامنهٔ `.ir` شما را مستقیماً از طریق پنل ثبت‌کنندهٔ ایرانی (مثلاً IRNIC یا یک
ثبت‌کنندهٔ محلی) مدیریت می‌کنید و API ندارد، دو گزینه دارید:

### گزینهٔ ۱ (پیشنهادی): انتقال مدیریت DNS به یک ارائه‌دهندهٔ دارای API

رایج‌ترین راه‌حل جامعهٔ ایرانی: ns های دامنه را به Cloudflare (رایگان) تغییر دهید،
بدون این‌که نیاز باشد IP اصلی سرور یا رکوردهای دیگر تغییر کند. این کار معمولاً
پایداری کلی DNS دامنه را هم بهبود می‌دهد.

### گزینهٔ ۲: حالت دستی DNS-01

```bash
DNS_PROVIDER="manual"
```

در این حالت، `acme.sh` در هر بار صدور/تمدید یک رکورد TXT به شما نشان می‌دهد که باید
آن را دستی در پنل DNS خود اضافه کنید و چند دقیقه صبر کنید تا تکثیر شود. برای تمدید
خودکار (بدون دخالت دستی) مناسب نیست؛ فقط برای صدور اولیه یا تست پیشنهاد می‌شود.
